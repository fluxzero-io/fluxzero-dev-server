# Fluxzero development workflows

Read setup for a new project or dependency integration; development before edits;
preview when showing or testing the app; monitoring for diagnosis; progress when
tracking functional work; startup for demo data. Fetch only relevant topics and
reuse the response while its server version and project remain unchanged.

Use docs_start and focused docs_search/docs_read for SDK knowledge, preserving
namespace and version. These workflows belong to the dev server, independently
of the project's SDK. Verify get_status and its project directory before acting.
Only start_dev starts development; workflow reads never start it.
