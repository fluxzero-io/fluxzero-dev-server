Monitoring settings

Monitoring starts by default for local Fluxzero backend apps. In .fluxzero/dev.yaml or your development profile, use:

monitoring:
  enabled: true

Set enabled: false to turn it off. Restart the Dev Server after changing this setting. Restarting resets in-memory app data.
